# ScrapLinker

Helpfeel Cosense 用のリンク（`[URL Title]` 形式）を、いま開いているタブからワンクリックで生成・コピーする Chrome 拡張です。

## 使い方

1. 拡張機能アイコンをクリック
2. 生成されたリンク文字列が選択された状態で表示されるので、Ctrl+C（Cmd+C）でコピーもしくは`COPY`ボタンをクリック

## 権限

- `tabs`：現在のタブのタイトルと URL を取得するために必要です。
